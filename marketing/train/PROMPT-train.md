# Музикална кутия с влакче – маркетингови снимки

Общи настройки: gpt_image_2_5 / sunburst / max / 4k / 4:5. Бранд: крем фон, бордо текст, жълто само като нежен акцент.
Референция за продукта: клиентската снимка на кутията с влакче (планина с тунел, две ярко зелени и едно тъмнозелено дърво, къщичка с оранжев покрив, влакче с два вагона, кръгли релси; гравюра отпред: МАРИЯ | 15.05.2024 / ПАЗИ ЧИСТАТА СИ ДЕТСКА ВЯРА. / С МАЛКИ СТЪПКИ КЪМ ГОЛЕМИ МЕЧТИ.).
Механизъм: основата НЕ се върти; влакчето е отделно, с магнит в него и магнит под дървото, и се движи по релсите, колелата се въртят.

## train-child.png – детска с икони (ФИНАЛНА)

- Ред с икони: „Нежна мелодия / тиха, без резки звуци“ | „Безопасно за деца / гладко натурално дърво“ | влакче „Движещо се влакче / като по магия“

## train-how-it-works.png – обяснителна в три стъпки (ФИНАЛНА)
Референции: постерът на въртележката how-it-works (типография), снимката на кутията в ръце (продукт и гравюра „Борис, пази детската си вяра / С Обич Мама и Тати“), снимката на долната страна с ключето, снимката на влакчето в длан.
- Целият фон крем; горе: ВМЕСТО УПЪТВАНЕ / Кой движи влакчето? (bold sans) / Магнит. (сериф, жълта четка)
- Три реда с тънки жълти разделители: вляво снимка в заоблен правоъгълник, вдясно жълт кръг с номер + заглавие + ред:
  1 долната страна на кутията в ръце, кръгла метална плоча с ключе, топчета-крачета, ръчка отстрани: „Навий ключето отдолу / ръчен механизъм, без батерии“
  2 пръсти поставят влакчето върху релсите: „Сложи влакчето на релсите / то е отделно и се държи с магнит“
  3 кутията с влакчето, жълта дъгова стрелка по релсите, икона магнит с пунктир отстрани на кутията: „Магнитът го повежда / върти се под дървото и колелцата тръгват по релсите“
